# Détail de la couverture, set par set

Mesure du 24 novembre 2026 (moteur après le lot F99, scripts Forge au commit `3e1fa4ed`). Même mesure que [couverture-detail.md](couverture-detail.md),
rangée cette fois selon les éditions de Forge (`res/editions`) : **658 sets** ayant au moins une carte à script, dont 409 hors promotionnels.

Règles de lecture :

- une carte compte dans **chacun** des sets où elle a été imprimée : la somme des lignes dépasse donc largement le nombre de cartes distinctes ;
- les terrains de base (Plains… Wastes, et leurs versions neiges) sont écartés — complets partout, ils ne disent rien ;
- une carte du set qui n'a pas de script Forge (jeton, carte numérique que Forge ne connaît pas) n'est pas comptée ;
- « Complètes » donne le nombre et la part ; partielles et injouables ont le sens du document précédent.
